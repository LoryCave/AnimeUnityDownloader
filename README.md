# AnimeUnity Downloader
Un'applicazione desktop per scaricare episodi di anime da AnimeUnity.

## Descrizione
**AnimeUnity Downloader** è un'applicazione Java con interfaccia grafica (JavaFX) che consente di ricercare e scaricare episodi di anime dal sito AnimeUnity. L'applicazione offre una gestione intelligente dei download, supporto per cartelle organizzate per anime, e una barra di progresso in tempo reale.

## Avvio Rapido
### Prerequisiti
- **Java 21+** installato sul sistema
- **Maven** per la compilazione (opzionale se usi i file precompilati)

### Installazione e Avvio
1. **Clona o scarica il progetto**
   ```bash
   git clone <url-repository>
   cd audw
   ```

2. **Compila il progetto**
   ```bash
   mvn clean package
   ```

3. **Esegui l'applicazione**
   ```bash
   java -jar target/audw-x.jar
   ```

   Oppure, usando Maven:
   ```bash
   mvn javafx:run
   ```

## Note Importanti
- L'applicazione è stata creata a scopo educativo e di intrattenimento
- Assicurati di rispettare i termini di servizio di AnimeUnity
- Non salvare contenuti in violazione ai diritti d'autore senza autorizzazione
